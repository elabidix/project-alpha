# project-alpha

Plan de 12 mois pour passer de **développeur senior Java / Spring / React** à **Senior Full-Stack AI Engineer** (agents, MCP, RAG, évaluation, gouvernance), avec un projet fil rouge commercialisable : **AgentGate**.

## Une seule source de vérité

| Je veux… | Je vais voir |
|---|---|
| Savoir quoi faire cette semaine, cocher l'avancement | [ROADMAP.md](./ROADMAP.md) (**seul fichier de suivi**) |
| Faire un TP (objectif, étapes, critères de réussite, ressources) | [labs/](./labs/README.md) (parcours, prérequis, conventions) |
| Comprendre pourquoi ces choix (analyse des offres) | [docs/market.md](./docs/market.md) |
| Consulter ou écrire une décision d'architecture | [docs/adr/](./docs/adr/README.md) |
| Coder le projet fil rouge | [agentgate/](./agentgate) |

Règle : l'état d'avancement ne se met **que** dans `ROADMAP.md` (cases à cocher + journal en bas). Les TP et la doc ne contiennent pas de statut.

## Positionnement visé

> Je mets en production des agents IA et du RAG dans des SI Java/Spring/React exigeants (banque en priorité, assurance, industrie) : sécurité, évaluation, observabilité, coûts.

## Démarrage rapide

1. Lire [docs/market.md](./docs/market.md) (10 min).
2. Ouvrir [ROADMAP.md](./ROADMAP.md), jalon **M0**, et lancer [lab-00](./labs/lab-00-agentic-workflow/README.md).
3. Chaque dimanche : cocher, mettre à jour le journal, planifier la semaine (rituel décrit dans la roadmap).
